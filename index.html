I build real-time AI agents at Microsoft Teams AI, working on Facilitator in Microsoft 365 Copilot. My focus is conversation orchestration, tool execution, context management, and multimodal meeting features that hold up in live conversation.

Previously, I built AR/VR interaction and multiplayer platforms at Holos, then was a key contributor to avatar rendering pipelines and shared UI at Microsoft Mesh. My background spans early-stage startups and large-scale interactive systems.
